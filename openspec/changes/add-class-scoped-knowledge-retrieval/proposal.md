## Why

当前知识库只保存材料全文，材料页的 `q` 搜索只返回材料级结果，无法定位段落、比较语义相近的表达或给出可核对的依据。第 4 课要求教师和学生在自己的班级内检索知识切片，并仅在有依据时生成带出处的简短回答。

## What Changes

- 新增独立知识检索入口，支持 `keyword`、`vector` 和默认的 `hybrid` 模式；三条路径只使用会话班级，混合模式以 RRF 融合排序。
- 上传和重建索引支持默认窗口、自定义分隔符与 Markdown 标题层级三种切分策略；原文保留，切片与向量可重建。
- 结果展示切片摘录、材料标题、切片序号、字符区间和来源跳转；无依据时返回固定文案，不以低相关候选凑数。
- 在前端左侧列出“知识问答”导航入口，主区域采用 chatbot 格式，连续展示用户问题、助手回答和每轮来源；支持发送、停止、失败重试及清空对话。后续请求携带有限历史，仅在本班混合检索取得依据后调用 `.env` 的 `CHAT_MODEL` 对话网关，并让回答中的 `[1]`、`[2]` 与引用列表对应。
- 对检索、问答、来源详情和下载复用现有认证与跨班同形 404 边界；索引未完成或依赖不可用时明确反馈。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 班级范围内的切分、三种检索、可核对引用、受依据约束的简短问答及索引恢复。

### Modified Capabilities

无。现有 `auth-upload` 仍是未归档 change 的 delta spec；本变更不修改它已定义的登录、上传和材料访问契约。

## Impact

- 实现涉及 Go API、MySQL 正文与切片、Qdrant 向量索引、服务端模型网关调用、React 检索/问答界面和 Compose 配置。
- 新增知识库检索及问答 API；现有 `/api/materials?q=...` 保持材料列表搜索语义。
- MySQL 继续保存权威原文和班级归属；Qdrant 仅保存向量和标识，不对宿主机公开。网关密钥仅配置在服务端。
- 不包含流式长对话、跨班检索或交叉编码器重排序。
